## Abstract

This spec documents gaps discovered during P1 implementation that block Nihil (MNIST training) from running correctly. These are not "nice to have" features—they are prerequisites that were implicit in the original spec but not explicitly documented.

Per SDD methodology: We stopped building, documented the gaps, and now formalize them before continuing.

**UPDATE:** All gaps have been implemented and verified. All tests pass.

## 2. Gap Details

### 2.1 Empty Array Literal

**Discovery:** Tests for `|zip` and `|count` with empty arrays cannot be written because `[]` is not parseable.

**Current Behavior:**
```sigil
≔ empty: [i64] = [];  // Parse error: unexpected token
```

**Required Behavior:**
```sigil
≔ empty: [i64] = [];  // Works, creates empty array of i64
≔ inferred = [];       // Works if type can be inferred
```

**Spec:**
- Parser must accept `[]` as valid array literal
- Type annotation required if type cannot be inferred from context
- `[].len()` returns `0`
- `[] |zip other` returns `[]`
- `[] |count` returns `0`
- `[] |count(predicate)` returns `0`

**Tests Required:**
```sigil
fn test_empty_array_literal() {
    ≔ empty: [i64] = [];
    assert(empty|len == 0, "Empty array has length 0");
}

fn test_empty_zip() {
    ≔ empty: [i64] = [];
    ≔ other = [1, 2, 3];
    ≔ zipped = empty|zip(other);
    assert(zipped|len == 0, "Zip with empty is empty");
}

fn test_empty_count() {
    ≔ empty: [i64] = [];
    assert(empty|count == 0, "Empty count is 0");
    assert(empty|count(|x| x > 0) == 0, "Empty predicate count is 0");
}
```

### 2.2 Parameter-Keyed Gradient Lookup

**Discovery:** `grads.get(&param)` returns first available gradient, not the specific gradient for the requested parameter.

**Current Behavior:**
```sigil
≔ w1 = Tensor·randn([4, 3]);
≔ w2 = Tensor·randn([3, 2]);
≔ y = (x @ w1) @ w2;
≔ grads = y|Σ|∇;

// Both return the SAME gradient (first found)
grads.get(&w1)  // Returns some gradient
grads.get(&w2)  // Returns same gradient (wrong!)
```

**Required Behavior:**
```sigil
grads.get(&w1)  // Returns gradient for w1 specifically
grads.get(&w2)  // Returns gradient for w2 specifically
grads.get(&unrelated)  // Returns None
```

**Spec:**
- Gradient map must key by tensor identity (Rc pointer)
- `grads.get(&tensor)` looks up by tensor identity
- Returns `Option::Some(grad_tensor)` if gradient exists
- Returns `Option::None` if tensor not in computation graph
- Gradient shape must match parameter shape

**Implementation Approach:**
1. Store tensor Rc pointer as key during backward pass
2. Look up by Rc pointer equality in `get()`
3. Compare `Rc::ptr_eq()` for identity matching

**Tests Required:**
```sigil
fn test_param_keyed_lookup() {
    ≔ w1 = Tensor·randn([4, 3]);
    ≔ w2 = Tensor·randn([3, 2]);
    ≔ x = Tensor·randn([2, 4]);

    ≔ y = (x @ w1) @ w2;
    ≔ grads = y|Σ|∇;

    ≔ g1 = grads.get(&w1).unwrap();
    ≔ g2 = grads.get(&w2).unwrap();

    // Critical: shapes must match their respective parameters
    assert(g1.shape() == [4, 3], "grad_w1 shape matches w1");
    assert(g2.shape() == [3, 2], "grad_w2 shape matches w2");
}

fn test_unrelated_returns_none() {
    ≔ w = Tensor·randn([3, 2]);
    ≔ x = Tensor·randn([2, 3]);
    ≔ y = x @ w;
    ≔ grads = y|Σ|∇;

    ≔ unrelated = Tensor·randn([5, 5]);
    assert(grads.get(&unrelated).is_none(), "Unrelated has no gradient");
}
```

### 2.3 Cross-Entropy Gradient Graph Preservation

**Discovery:** `cross_entropy()` breaks the gradient computation graph.

**Current Behavior:**
```sigil
≔ logits = x @ w;
≔ loss = cross_entropy(logits, targets);
≔ grads = loss|∇;
grads.get(&w)  // Returns None - graph not preserved through cross_entropy
```

**Required Behavior:**
```sigil
grads.get(&w)  // Returns Some(gradient) - graph preserved
```

**Spec:**
- `cross_entropy(logits, targets)` must preserve `_grad_left` reference
- Backward pass through cross_entropy computes: `grad = softmax(logits) - one_hot(targets)`
- Gradient flows back to logits, then through matmul to weights

**Implementation Approach:**
1. When `cross_entropy` creates result, store `_grad_input` pointing to logits tensor
2. In backward pass, recognize cross_entropy node and compute gradient
3. Propagate gradient to logits' backward graph

**Tests Required:**
```sigil
fn test_cross_entropy_gradient_exists() {
    ≔ w = Tensor·randn([4, 3]);
    ≔ x = Tensor·randn([2, 4]);
    ≔ logits = x @ w;
    ≔ loss = cross_entropy(logits, [0, 1]);
    ≔ grads = loss|∇;

    assert(grads.get(&w).is_some(), "CE gradient exists");
}

fn test_cross_entropy_gradient_shape() {
    ≔ w = Tensor·randn([4, 3]);
    ≔ x = Tensor·randn([2, 4]);
    ≔ logits = x @ w;
    ≔ loss = cross_entropy(logits, [0, 1]);
    ≔ grads = loss|∇;

    ≔ gw = grads.get(&w).unwrap();
    assert(gw.shape() == [4, 3], "CE gradient shape matches param");
}
```

### 2.4 Zero Gradients Method

**Discovery:** Optimizer training loop pattern requires zeroing gradients between iterations.

**Current Behavior:**
```sigil
// No way to zero gradients between training steps
```

**Required Behavior:**
```sigil
∀ epoch ∈ 0..num_epochs {
    ≔ loss = forward(batch);
    ≔ grads = loss|∇;

    // Apply gradients
    w = w - learning_rate * grads.get(&w).unwrap();

    // Zero gradients for next iteration
    grads.zero();  // Or clear accumulated gradients on tensors
}
```

**Spec:**
- `grads.zero()` clears all gradients in the Gradients struct
- Alternative: `tensor.zero_grad()` clears gradient on specific tensor
- Must support both accumulation (for gradient accumulation) and zeroing

**Implementation Approach:**
1. Add `zero()` method to Gradients struct
2. Clears the internal `__grads__` HashMap
3. Optionally reset `grad` field on tracked tensors

**Tests Required:**
```sigil
fn test_zero_gradients() {
    ≔ w = Tensor·randn([3, 2]);
    ≔ x = Tensor·randn([2, 3]);

    // First backward
    ≔ loss1 = (x @ w)|Σ;
    ≔ grads1 = loss1|∇;
    assert(grads1.get(&w).is_some(), "Gradient exists");

    // Zero
    grads1.zero();
```

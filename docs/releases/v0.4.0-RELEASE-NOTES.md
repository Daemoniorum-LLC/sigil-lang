# Sigil v0.4.0 Release Notes

**Release Date:** January 25, 2026

## Overview

Sigil v0.4.0 represents a major milestone: the transition to native syntax and the foundation for self-hosting. This release achieves **85% test pass rate (509/596)** with all P0 (stable) tests passing, and completes the migration from Rust-like syntax to Sigil's native symbol vocabulary.

## Highlights

### Native Syntax

Sigil now speaks its own language:

| Old (Deprecated) | New (Native) | Meaning |
|-----------------|--------------|---------|
| `fn` | `λ` | Function declaration |
| `struct` | `Σ` | Struct declaration |
| `let` | `≔` | Variable binding |
| `::` | `·` (middledot) | Module path separator |
| `&mut` | `&Δ` | Mutable reference |
| `for` | `∀` | Universal quantification |
| `loop` | `∞` | Infinite loop |
| `break` | `⊗` | Break |
| `continue` | `↻` | Continue |

Use `sigil migrate` to automatically upgrade your code.

### Zero C Dependency Runtime

The native runtime (`parser/src/rt/`) replaces the C runtime with pure Sigil/assembly:

- Platform syscalls for Linux x64/ARM64, macOS Intel/ARM, Windows
- Arena allocator with O(1) allocation
- SIMD vector math (SSE/AVX/AVX-512)
- Native file I/O, networking, and threading

### SGDOC Documentation System

Extract documentation from Sigil source with evidential markers:

```bash
sigil doc-extract src/lib.sg --format=html -o docs/
```

**Evidentiality Markers:**
- `//!` - Verified (proven by tests)
- `//~` - Reported (from external sources)
- `//?` - Uncertain (needs verification)
- `//◊` - Predicted (future functionality)
- `//‽` - Paradox (inherent contradictions)

### Tooling

- **LSP Server**: Full Language Server Protocol support
- **Formatter**: `sigil fmt` with configurable style
- **Linter**: `sigil lint` with evidentiality checking
- **Package Manager**: `tome` for dependency management

### Compute Backends

- **SIMD**: AVX-512 F32x16 operations
- **CUDA**: GPU compute via `--cuda` flag
- **LTO**: Link-time optimization via `--lto` flag

## Breaking Changes

1. **Rust syntax deprecated**: `fn`, `let`, `struct`, `::` emit errors with migration hints
2. **Module paths**: Use middledot (`·`) instead of double colon (`::`)
3. **Doc comments**: Use SGDOC markers instead of `///`

## Migration Guide

### Automatic Migration

```bash
sigil migrate src/
```

### Manual Changes

```sigil
// Before (v0.3.0)
fn greet(name: String) -> String {
    let msg = "Hello, " + name;
    return msg;
}

// After (v0.4.0)
λ greet(name: String) -> String {
    ≔ msg = "Hello, " + name;
    msg  // Expression-based return
}
```

## Known Issues

- **P1/P2 Tests**: 87 failing tests are mostly experimental features (native runtime, neural ops, protocols)
- **Native Runtime**: `as_bytes()` and `clear()` methods not yet implemented for String/Array
- **WebSocket/HTTP**: Protocol tests require live endpoints for verification

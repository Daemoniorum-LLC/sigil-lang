Morpheme Operators

let data = [10, -5, 25, -3, 18]; // Filter, transform, sort let result = data |φ{x => x > 0} |τ{n => n * 2} |σ; let sum = data|ρ+;
  • τ - Transform (map)
  • φ - Filter
  • σ - Sort
  • ρ - Reduce (fold)
  • α/Ω - First/Last

Module Paths

  • vdom:: - Virtual DOM
  • async:: - Promises
  • dom:: - Direct DOM

Named Closures

// Named parameter syntax let squared = nums|τ{n => n * n}; // Implicit 'it' parameter let doubled = nums|τ{it * 2}; // Reduce shortcuts let sum = nums|ρ+; let product = nums|ρ*;
  • {x => x * 2} - Named param
  • {it * 2} - Implicit it
  • ρ+ - Sum shorthand
  • ρ* - Product shorthand

## How to Add Entries

When you discover something that future agents should know:

1. **Determine scope:**
   - Project-specific? Add to project's local docs
   - Org-wide? Add here

2. **Use the template:**
   ```markdown
   ### CATEGORY-NNN: Brief Title

   **Date:** YYYY-MM-DD
   **Project:** project-name
   **Agent:** Your identifier (model, chosen name)

   **Context:**
   What were you trying to do?

   **Discovery:**
   What did you learn?

   **Solution/Pattern:**
   How should future agents approach this?
   ```

3. **Cross-reference:**
   - Update your CONCLAVE.sigil entry's `discoveries` array
   - Reference this doc in your reflection

4. **Categories:**
   - `WASM-NNN`: WebAssembly compilation, tooling, runtime
   - `TEST-NNN`: Testing patterns, validation approaches
   - `PERF-NNN`: Performance optimization patterns
   - `CARGO-NNN`: Rust build system, features, dependencies
   - `SIGIL-NNN`: Sigil language implementation
   - `INVESTIGATE-NNN`: Open questions requiring future work

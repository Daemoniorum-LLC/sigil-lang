The Grimoire

The Grimoire is Sigil's package registry and dependency manager. It lets you discover, share, and manage reusable tomes (packages) of Sigil code.

Ritual Commands

Evocative commands like conjure, summon, and forge for intuitive package management.

Simple Bindings

Declare dependencies with version, path, or git bindings in Grimoire.toml.

Reproducible Builds

Grimoire.lock ensures consistent builds across environments.

Quick Start

Create a New Tome

# Conjure a new tome into existence
$ sigil conjure my-tome
    Created tome 'my-tome' at ./my-tome

$ cd my-tome
$ tree
.
├── Grimoire.toml
├── .gitignore
└── src
    └── main.sg

Add a Dependency

# Summon the aegis security library
$ sigil summon aegis
    Added aegis = "0.2" to [bindings]

# Or with a specific version
$ sigil summon chorus "^0.1"
    Added chorus = "^0.1" to [bindings]

Build Your Project

# Forge shapes your tome into being
$ sigil forge
    Attuning bindings...
    Resolved aegis 0.2.1
    Resolved chorus 0.1.3
    Forged my-tome v0.1.0

Grimoire.toml

Every Sigil tome has a Grimoire.toml manifest file:

# Tome metadata
[tome]
name = "my-tome"
version = "0.1.0"
authors = ["Your Name <you@example.com>"]
edition = "2026"
description = "A brief description of your tome"
license = "MIT"
repository = "https://github.com/you/my-tome"

# Dependencies (bindings)
[bindings]
aegis = "0.2"                      # Registry binding
chorus = { version = "^0.1" }       # Detailed version
local-lib = { path = "../lib" }    # Local path
utils = { git = "https://github.com/org/utils" }

# Dev-only dependencies
[dev_bindings]
test-utils = "0.1"

# Custom scripts (rites)
[rites]
test = "sigil run tests/all.sg"
bench = "sigil run benchmarks/main.sg"

sigil conjure

Summon a new tome into existence. Creates a new project with standard structure.

$ sigil conjure <name> [path]

# Examples:
$ sigil conjure my-app           # Creates ./my-app/
$ sigil conjure my-lib ./libs    # Creates ./libs/my-lib/

sigil inscribe

Mark an existing directory as a tome. Useful for converting existing projects.

$ sigil inscribe
    Inscribed Grimoire.toml in current directory

sigil summon

Call forth a dependency and add it to your bindings.

$ sigil summon <tome> [version]

# Examples:
$ sigil summon aegis             # Latest version
$ sigil summon aegis "0.2"       # Exact version
$ sigil summon aegis "^0.2"      # Compatible with 0.2.x
$ sigil summon aegis "path:../aegis"  # Local path
$ sigil summon aegis "git:https://..."  # Git repository

sigil banish

Cast out a dependency from your bindings.

$ sigil banish <tome>

# Example:
$ sigil banish old-dep
    Banished old-dep from [bindings]

sigil attune

Realign with latest binding versions. Downloads and resolves all dependencies.

$ sigil attune
    Fetching registry index...
    Resolving aegis ^0.2 → 0.2.1
    Downloading aegis-0.2.1.tar.gz
    Extracting to .tomes/aegis-0.2.1/
    Attuned 3 bindings

sigil forge

Shape the tome into being. Builds your project with all dependencies.

$ sigil forge
    Forged my-tome v0.1.0 (src/main.sg)

sigil consecrate

Enshrine your tome in the Grimoire registry for others to use.

$ sigil consecrate
    Packaging my-tome v0.1.0...
    Uploading to grimoire registry...
    Consecrated my-tome v0.1.0

Version Bindings

Specify dependencies from the Grimoire registry using version requirements:

Syntax Meaning Example Match
"1.2.3" Exact version 1.2.3 only
"^1.2" Compatible (same major) 1.2.0, 1.3.0, 1.9.9
"~1.2" Patch updates only 1.2.0, 1.2.1, 1.2.9
"*" Latest stable Latest version

Path Bindings

Use local paths for development or monorepo setups:

[bindings]
# Detailed syntax
my-lib = { path = "../my-lib" }

# Inline syntax when summoning
$ sigil summon my-lib "path:../my-lib"

Git Bindings

Pull dependencies directly from git repositories:

[bindings]
# Basic git binding (uses default branch)
utils = { git = "https://github.com/org/utils" }

# Specific branch
utils = { git = "https://github.com/org/utils", branch = "develop" }

# Specific tag
utils = { git = "https://github.com/org/utils", tag = "v1.0.0" }

# Specific commit
utils = { git = "https://github.com/org/utils", rev = "a1b2c3d" }

Preparing a Tome for Publishing

Before consecrating your tome to the Grimoire, ensure:

  • Your Grimoire.toml has all required fields (name, version, description, license)
  • The version follows Semantic Versioning
  • Your code compiles without errors: sigil forge
  • Tests pass (if you have them)

Publishing to the Registry

# Verify your manifest
$ sigil forge

# Consecrate to the Grimoire
$ sigil consecrate
    Packaging aegis v0.2.1...
    Verifying manifest...
    Creating aegis-0.2.1.tar.gz (12.4 KB)
    Uploading to https://sigil-lang.com/grimoire/
    Consecrated aegis v0.2.1

# Your tome is now available!
$ sigil summon aegis "0.2.1"

Versioning Guidelines

The Grimoire uses Semantic Versioning:

  • MAJOR (1.0.0 → 2.0.0): Breaking API changes
  • MINOR (1.0.0 → 1.1.0): New features, backward compatible
  • PATCH (1.0.0 → 1.0.1): Bug fixes, backward compatible

Yanking Versions

If you publish a broken version, you can yank it to prevent new installations:

# Yank a specific version
$ sigil yank aegis 0.2.0
    Yanked aegis v0.2.0

# Existing projects with this version in Grimoire.lock still work
# New installations will skip yanked versions

Manifest Reference

Complete Grimoire.toml field reference:

[tome] Section

Field Required Description
nameYesTome name (lowercase, hyphens allowed)
versionYesSemantic version (MAJOR.MINOR.PATCH)
authorsNoList of author names/emails
editionNoSigil edition year (e.g., "2026")
descriptionNo*Short description (*required for publishing)
licenseNo*SPDX license identifier (*required for publishing)
repositoryNoSource repository URL
homepageNoProject homepage URL
keywordsNoDiscovery keywords (max 5)
categoriesNoCategory tags

Grimoire.lock

The lock file records exact versions for reproducible builds:

version = 1

[[bindings]]
name = "aegis"
version = "0.2.1"
source = "registry"
checksum = "sha256:a1b2c3d4..."
dependencies = []

[[bindings]]
name = "utils"
version = "0.0.0-git"
source = "git:https://github.com/org/utils#main"
dependencies = ["aegis"]

Tip: Commit Grimoire.lock for applications. Exclude it for libraries.

Registry API

The Grimoire registry is a simple static file server:

https://sigil-lang.com/grimoire/
├── index.json           # Registry index
└── tomes/
    └── aegis/
        ├── 0.1.0.tar.gz
        └── 0.2.1.tar.gz

Index Format

{
  "tomes": {
    "aegis": {
      "description": "Security primitives for Sigil",
      "versions": ["0.2.1", "0.2.0", "0.1.0"],
      "latest": "0.2.1",
      "yanked": ["0.2.0"]
    }
  }
}

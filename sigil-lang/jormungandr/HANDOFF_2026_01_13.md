### Root Causes Identified

1. **Closure self capture**: Closures reference `self` but it's not in scope
   - Location: `sigil_closure_TypeChecker____*` functions (lines 8274-8292)
   - Need to pass self as parameter or capture in closure struct

2. **Variable name duplication**: Short variable names get doubled
   - Examples: `source` → `sourcesource`, `name` → `namename`
   - Likely a string concatenation bug in emit_operation or lower

3. **Format string corruption**: format! macro not properly lowered
   - Example: `format!("...", self.source)` → `sigil_format(sourcesource)`
   - Format string completely missing, arguments corrupted

4. **Missing TAG_MAP**: Runtime constant not defined
   - Line 44422: `TAG_MAP` undeclared

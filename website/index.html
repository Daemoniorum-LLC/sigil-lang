Sigil

A programming language that knows which data to trust.

Sigil tracks data provenance in the type system:

  • ! Known — verified, computed locally
  • ? Uncertain — might be absent
  • ~ Reported — external source, untrusted
  • ‽ Paradox — explicit trust boundary

The Bug That Types Can't Catch

In every other language, this code compiles. In Sigil, it's a type error.

Rust / TypeScript / Go Compiles. Vulnerable. 
// This compiles in every mainstream language
async fn get_user_profile(id: String) -> Profile {
    let response = http::get("/api/users/{id}").await;
    let profile: Profile = response.json();

    // profile is type Profile
    // But it came from an external API!
    // What if the API was compromised?
    // What if the data was tampered?

    save_to_database(profile);  // Trusting blindly
    profile
}
Sigil Type Error. Safe. 
async fn get_user_profile(id: Str) -> Profile! {
    let response~ = http::get("/api/users/{id}").await;
    let profile~: Profile~ = response.json();

    // profile~ is type Profile~ (Reported)
    // The ~ marker propagates automatically

    save_to_database(profile);  // ERROR: expected Profile!, got Profile~

    // Must validate first:
    let verified! = profile |validate!{ verify_signature() };
    save_to_database(verified);  // OK: Profile!
    verified
}

The ~ marker is contagious. Any data derived from external sources inherits the ~ until explicitly validated. You can't accidentally trust untrusted data.

Evidentiality: Data Has a History

Every value carries proof of where it came from.

!

Known

Verified truth

Data you computed yourself, or explicitly verified. Safe to trust.

let sum! = 2 + 2           // Computed locally
let valid! = input |validate!{ check() }
?

Uncertain

Might be absent

Data that might not exist. Like Option/Maybe, but tracked in the type.

let user? = database.find(id)  // Might not exist
let name? = user?.profile?.name   // Propagates
~

Reported

External source

Data from APIs, user input, files. Never trust without validation.

let data~ = api.fetch(url)     // External
let input~ = form.get("email")   // User input
‽

Paradox

Trust boundary

Explicit "I know what I'm doing" escape hatch. Use sparingly.

let ptr‽ = unsafe { raw_pointer }
// You're taking responsibility

The Propagation Rule

When you combine data, the result inherits the worst evidence level:

let local! = 100                    // Known
let remote~ = api.get_multiplier()   // Reported
let result~ = local * remote          // Known + Reported = Reported
//       ^ automatically inferred as ~ because remote is untrusted

Morpheme Operators

Greek letters for data transformation. Dense, readable pipelines.

let result = users~
    |φ{.active}              // φ filter: keep active users
    |φ{.age >= 18}           // φ filter: adults only
    |τ{.normalize()}         // τ transform: normalize each
    |σ·by{.created_at}       // σ sort: by creation date
    |validate?               // promote to uncertain after checks
    |τ{.to_public_profile()} // τ transform: strip private data
    |validate!               // promote to known after verification

struct Todo { id: u64, text: String, done: bool }
struct Store { todos: Vec<Todo>, next_id: u64 }

impl Store {
    fn new() -> Self {
        Store { todos: Vec::new(), next_id: 1 }
    }

    fn add(&mut self, text: &str) -> Result<Todo, Error> {
        let clean = text.trim();
        if clean.is_empty() {
            return Err(Error::Empty);
        }
        let todo = Todo {
            id: self.next_id,
            text: clean.to_string(),
            done: false,
        };
        self.todos.push(todo.clone());
        self.next_id += 1;
        Ok(todo)
    }

    fn toggle(&mut self, id: u64) -> Option<&Todo> {
        if let Some(todo) = self.todos.iter_mut()
            .find(|t| t.id == id) {
            todo.done = !todo.done;
        }
        self.todos.iter().find(|t| t.id == id)
    }

    fn remove(&mut self, id: u64) {
        self.todos.retain(|t| t.id != id);
    }

    fn active(&self) -> Vec<&Todo> {
        self.todos.iter().filter(|t| !t.done).collect()
    }

    fn completed(&self) -> Vec<&Todo> {
        self.todos.iter().filter(|t| t.done).collect()
    }

    fn clear_done(&mut self) {
        self.todos.retain(|t| !t.done);
    }
}

Get Started

  1. Install

    From source (requires Rust) 
    git clone https://github.com/Daemoniorum-LLC/sigil-lang
cd sigil-lang/parser && cargo build --release
# Binary at: target/release/sigil

    Package manager support (Homebrew, apt) coming soon.

  2. Write

    // hello.sigil
fn main() {
    let name! = "World"
    println("Hello, {name}!")
}

  3. Run

    $ sigil run hello.sigil

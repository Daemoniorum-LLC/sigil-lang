## ⚠️ Remaining Issue

### Segmentation Fault in Nested Match
**Problem:** The nested match syntax in `src/lower.sg` causes a segfault when compiling full source:

```sigil
let type_mutable = match param.ty {
    ?t => match t {  // ← Nested match causes crash
        TypeExpr::Reference { mutable: m, .. } => m,
        _ => false,
    },
    null => false,
};
```

**When:** sig il2_final (compiled from fixed source) crashes when compiling full src/*.sg
**Exit Code:** 139 (SIGSEGV)
**Output:** Empty file (0 bytes)

### Why This Happens
The compiler has a bug handling nested match expressions - probably in how it generates or evaluates the inner match. This is a separate compiler bug from our bootstrap issue.

## 🔧 Solution Path Forward

### Option A: Flatten the Match (RECOMMENDED)
Rewrite the lower_param fix without nested match:

```sigil
let type_mutable = match param.ty {
    ?TypeExpr::Reference { mutable: m, .. } => m,
    ?_ => false,
    null => false,
};
```

Or use an if-let chain:

```sigil
let type_mutable = if let ?t = param.ty {
    match t {
        TypeExpr::Reference { mutable: m, .. } => m,
        _ => false,
    }
} else {
    false
};
```
